# 0_怎麼填寫（主檔範本）

這裡的 CSV 是給你**手動填寫**的主檔。用 **Excel** 或記事本打開，
**第一列（欄位名）不要改**，照著往下填或修改既有列。

| 檔名 | 是什麼 | 重點欄位（中文說明） |
|---|---|---|
| `app_user.csv` | 人員 | employee_no＝員編、display_name＝姓名、department＝部門、role_name＝角色、is_active＝啟用(true/false) |
| `equipment_group.csv` | 設備群組 | group_code＝代碼、group_name＝名稱、system_name＝系統、online_required_qty＝上線需求量、min_safety_spare_qty＝最低安全備品、warning_spare_qty＝警戒量 |
| `instrument.csv` | 儀器／工具 | instrument_no＝編號、instrument_name＝名稱、location＝放置位置、calibration_due_date＝校驗到期日(YYYY-MM-DD)、status＝狀態、keeper_name＝保管人(填姓名即可，系統會自動對應人員) |
| `wi_document.csv` | 工作說明書 WI | wi_no＝編號、wi_name＝名稱、wi_type＝類別、version_no＝版次、status＝狀態 |
| `pm_template_material.csv` | 各等級**用料** | pm_code＝等級(P1~P4)、part_no＝料號、default_qty＝數量、default_unit＝單位 |
| `pm_template_instrument.csv` | 各等級**儀器** | pm_code＝等級(P1~P4)、instrument_no＝儀器編號 |
| `pm_template_wi.csv` | 各等級 **WI** | pm_code＝等級(P1~P4)、wi_no＝WI 編號 |

> 等級代碼：`P1`＝月檢、`P2`＝季檢、`P3`＝半年檢、`P4`＝年檢。每個等級可有多列（一列一項）。

## 怎麼匯入資料庫
等有 Postgres 後，在 `db-design` 目錄執行：

```
psql "你的資料庫連線字串" -f import-master-data.sql
```

`pm_template_*.csv`（各等級用料/儀器/WI）改用這支（要先匯入物料、儀器、WI）：

```
psql "你的資料庫連線字串" -f import-pm-templates.sql
```

## 改了想更新？（初期可一直改）
直接改 CSV，**再跑一次** `import-master-data.sql` 就會**覆蓋更新**。
- 以「代碼」為鍵：人員看 `employee_no`、設備群組看 `group_code`、儀器看 `instrument_no`、WI 看 `wi_no`。
- 同代碼 → 更新；新代碼 → 新增。

## 填寫小提醒
- 日期格式用 `2026-12-31`；沒有日期（例如免校驗）可填 `N/A` 或留空。
- `is_active` 只填 `true` 或 `false`。
- 沒有的欄位留空即可，不要刪欄位。
- 存檔請保持 **CSV（逗號分隔、UTF-8）** 格式。
