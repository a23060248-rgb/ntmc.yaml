## F. 建議動工順序（草案，待確認）

1. **先接出已有的隱藏欄位**：API 回傳 `category_name` 等 5 欄 → HTML 多一欄「細分類」。零風險、立刻有感。
2. **接年用量**：API join `material_usage_history` → 主控版「預估年用量」有值。
3. **清分類值**：收斂 system_name／unit 與清單對齊。
4. **補缺口資料**：單價、交期等批次匯入。
5. **新增欄位**：依 E 區討論結果，一次改 schema + API + HTML。
