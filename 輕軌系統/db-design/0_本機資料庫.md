# 0_本機資料庫（架在這個資料夾，不上雲端）

把 PostgreSQL 的「資料叢集」建在專案外層 `../.runtime/pgdata`，避免 Windows PostgreSQL 因中文路徑無法啟動。
本機執行、不上雲端；要砍掉重來，停掉後刪除外層 `.runtime/pgdata` 即可。

## 一次性：安裝 PostgreSQL（只需一次）
打開 PowerShell 執行：

```
winget install -e --id PostgreSQL.PostgreSQL
```

> 安裝過程若跳出設定畫面，密碼隨意設、port 用預設都沒關係——我們的資料庫是另外建在資料夾、用 5433 連，不會用到它的預設服務。

## 第一次建庫（只需一次）
在 `db-design` 目錄執行：

```
powershell -ExecutionPolicy Bypass -File local-db-init.ps1
```

它會自動做完：
1. 在外層 `.runtime/pgdata` 建立資料叢集（本機免密碼）
2. 啟動資料庫（port 5433）
3. 建立資料庫 `ntmc_erp`
4. 依序灌入：schema → 種子 → 清單選項 → 淡海物料 → 你在 `templates/` 填的主檔 → 各等級對應
5. 把 `erp-api/.env` 的 `DATABASE_URL` 指到本機

## 平常開關
```
powershell -ExecutionPolicy Bypass -File local-db-start.ps1   # 開機後啟動
powershell -ExecutionPolicy Bypass -File local-db-stop.ps1    # 關閉
```

## 連線資訊
```
主機 localhost   port 5433   資料庫 ntmc_erp   使用者 postgres（本機免密碼）
DATABASE_URL = postgresql://postgres@localhost:5433/ntmc_erp
```

## 啟動後端 API
```
cd ..\erp-api
npm install        （第一次）
npm start          → http://localhost:3001/api/health
```

## 改了資料想重灌？
- 改了 `templates/*.csv` → 重跑 `import-master-data.sql` / `import-pm-templates.sql`（冪等覆蓋）。
- 想整個重來 → 跑 `local-db-stop.ps1`，刪掉外層 `.runtime/pgdata` 資料夾，再跑 `local-db-init.ps1`。

## 之後要上雲端？
`erp-api/.env` 內已保留雲端網址（註解狀態）。把本機那行註解、解開雲端那行即可切換，程式不用改。

## 注意
- 外層 `.runtime/` 已加入 `.gitignore`，不會進版控。
- 這套腳本是 Windows / PowerShell 版;尚未在你機器實跑過,第一次執行我陪你看結果、有問題即時修。
