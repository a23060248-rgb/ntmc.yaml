# 0_從這裡開始（資料夾導覽）

這個資料夾檔案很多，但**你平常只會做兩種事**：

## 🅰 我要「填資料」
→ 打開 **`templates/` 資料夾**（裡面有中文說明 `0_怎麼填寫.md`）

| 檔名 | 填什麼 |
|---|---|
| `templates/app_user.csv` | 人員 |
| `templates/equipment_group.csv` | 設備群組（上線需求量、安全備品水位） |
| `templates/instrument.csv` | 儀器／工具 |
| `templates/wi_document.csv` | 工作說明書 WI |
| `templates/pm_template_material.csv`／`_instrument.csv`／`_wi.csv` | 各等級 P1~P4 的用料／儀器／WI 對應（進階） |

其他較大的待填資料：
- `material-catalog-tamhai.csv`：物料主檔（淡海，已填好可檢查）
- `material-usage-history-template.csv`：歷史用量（範本待填）
- `asset-installation-field-checklist-tamhai.csv`：現場盤點設備序號（現場填）

## 🅱 我要「把資料灌進資料庫」（等有 Postgres 時）
照這個順序跑（用 psql）：
1. `schema.postgres.sql` — 建表（只跑一次）
2. `seed-reference-data.sql` — 人員／車號／倉庫／設備群組／物料／儀器／WI／PM 基本種子
3. `seed-repair-workflow-options.sql` — 維修流程選項
4. `seed-reference-lists.sql` — 系統別／單位／工單類型／專案階段·狀態 等下拉清單
5. `material-import-tamhai.sql` — 淡海物料＋庫存
6. `import-master-data.sql` — 你在 `templates/` 填的人員／設備群組／儀器／WI
7. `import-pm-templates.sql` — 各等級（P1~P4）用料／儀器／WI 對應

（坑位、現場盤點序號等，需要時再依 `README.md` 的順序跑）

> 💡 想在本機一鍵建好整個資料庫？看 **`0_本機資料庫.md`**（用 `local-db-init.ps1` 自動把上面這些依序灌完，資料就在本資料夾、不上雲端）。

## 其餘檔案平常不用動
- `docs/`、`*-design.md`、`*-guide.md` … 設計說明（想深入再看）
- `*.ps1` … 產生器（工程用）
- `README.md` … 完整檔案清單與規則

---
👉 一句話：**要填資料 → 進 `templates/`；要灌資料庫 → 照 🅱 的順序跑 .sql。**
