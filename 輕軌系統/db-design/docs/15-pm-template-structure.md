# 預檢模板結構與匯入審核

## 目的

預檢模板的檢查項目、數位附件與 Word 版面分開維護，但每張 P 工單必須保留建立當下的完整版本快照。使用者可以隨時修改下一版 P1/P2/P3/P4，既有工單、歷史回填與已輸出的 Word 不會被改寫。

## 正式結構

| 資料 | 用途 | 修改規則 |
| --- | --- | --- |
| `pm_template` | P1/P2/P3/P4 模板版本 | 草稿可編輯；發布後只能新增修訂版 |
| `pm_template_section` | 區段代碼、名稱、排序與顯示設定 | 僅草稿模板可編輯 |
| `pm_template_check_item` | 檢查項目與量測標準 | 連到 `section_id`；保留 `section` 欄位相容舊資料 |
| `pm_attachment_definition` | 可重複使用的附件主檔，例如座椅圖、量測表 | 只保存穩定代碼與名稱；停用後不可再選用 |
| `pm_attachment_definition_version` | 附件 schema、欄位、判定標準與 Word 輸出策略 | 草稿可編輯；發布後只能建立新修訂 |
| `pm_template_attachment` | P 模板版本選用的附件版本、帶入條件與排序 | 只綁定已發布附件版本；同時保存內嵌快照 |
| `form_template` | 原始 Word 範本版本 | 發布後不可修改 |
| `form_template_*_mapping` | 數位欄位到 Word 落點 | 僅草稿 Word 範本可修改 |
| `pm_work_order.template_snapshot` | 工單建立當下的完整快照 | 開始產生 Word 後不可變更 |

## 修改下一版模板

1. 從目前發布版本建立修訂版，狀態為 `DRAFT`。
2. 調整區段、檢查項目、用料、儀器、WI，並從附件模板庫選用已發布附件版本。
3. 建立或選擇相容的 Word 範本版本，完成欄位與區塊 mapping。
4. 執行發布檢核：至少有檢查項目、WI、已發布 Word，且數位項目與 Word 落點覆蓋一致。
5. 發布新版本。舊版本自動退版，新建立的 P 工單才會使用新版本。

## 附件模板庫與自動帶入

附件不是直接在 P1/P2/P3/P4 內重畫，而是先在「主檔設定 → 附件模板庫」設計與發布：

1. 建立穩定的附件代碼，例如 `P1-SEAT` 或 `P1-MAG-BRAKE`。
2. 在附件草稿版本調整座椅配置、量測點、欄位、單位、上下限、必填條件與 Word 輸出策略。
3. 發布附件版本。發布後內容不可修改；變更時建立新修訂。
4. 到「預檢表單設計 → 附件選用」，由 P 模板草稿選擇已發布附件版本，設定固定帶入／列印前選擇、必填與排序。
5. P 模板發布後，新建立的 P 工單會連同預設用料、儀器、WI、附件及 Word mapping 一起建立不可變快照。

既有已發布 P 模板若原本使用內嵌附件，migration 只建立對應的附件模板庫版本，不會改寫已發布模板。下一個 P 模板修訂才可改選正式附件版本。

## Word 擷取暫存流程

從 Word 擷取的項目不得直接寫入正式模板。流程是：

1. 建立 `pm_template_check_item_import_batch`。
2. 每筆候選項目寫入 `pm_template_check_item_import_row`，保留來源頁碼、列號與原始 payload。
3. 業務逐筆調整名稱、區段、檢查型態、量測標準與必填條件。
4. 只有所有必要項目核准後，才套用到新的草稿模板。
5. 發布前仍需通過 Word mapping 覆蓋率檢核。

## 資料庫防線

- 已發布附件版本不可修改；只能建立附件新修訂並重新發布。
- P 模板只能選擇已發布附件版本，附件草稿不得帶入工單。
- 已發布或已退版模板的區段、檢查項目、附件選用、用料、儀器與 WI 不能直接新增或修改。
- 有 `GENERATING` 或 `READY` 列印紀錄的 P 工單不得更換模板快照或 Word 範本。
- 實體刪除不作為日常維護操作；對下一版的調整使用新修訂版，對不再使用的內容使用停用。
