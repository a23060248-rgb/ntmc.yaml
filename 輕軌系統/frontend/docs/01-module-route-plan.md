# 模組、頁面與路由規畫

更新日期：2026-07-10

## 1. 全域頁面

| 路由 | 頁面 | 說明 |
| --- | --- | --- |
| `/login` | 登入 | 正式環境身分驗證 |
| `/unauthorized` | 無權限 | 權限不足提示 |
| `*` | 找不到頁面 | 回主儀表板或顯示 404 |

展示版仍使用 HashRouter，實際網址會是 `#/work-orders` 形式。

## 2. 主儀表板

| 路由 | 頁面 | 第一版內容 |
| --- | --- | --- |
| `/` | 維修主儀表板 | 今日工作、待辦、異常、逾期與跨模組摘要 |

區塊：

- 今日 P/C/R/J 工單
- 待回填 P 工單、待派工 C 工單、待處理 R 工單
- 逾期與高風險提醒
- 周轉件空坑、送修、待驗收摘要
- 物料低於請購點摘要
- 點摘要直接帶篩選條件進入對應模組

## 3. 工單管理

| 路由 | 頁面 | 功能 |
| --- | --- | --- |
| `/work-orders` | 工單清冊 | 查詢全部工單；預設聚焦 C/R/J，P 可唯讀查詢 |
| `/work-orders/new/fault` | 新增 C 工單 | 故障通報、車號/設備、坑位、故障分類 |
| `/work-orders/:workOrderNo` | 工單詳情 | 摘要、作業、用料、附件、歷程 |
| `/work-orders/:workOrderNo/finish` | 完工作業 | 完工報告、工時、結果與異常 |
| `/work-orders/repairs` | R 維修清冊 | 待處理、維修中、已入庫、已報廢 |
| `/work-orders/repairs/:workOrderNo` | R 工單詳情 | 來源 C 單、拆下件、位置、外修、驗收與事件 |
| `/work-orders/projects` | J 專案清冊 | 改善案、改造案與批次專案 |

重要規則：

- 工單主頁使用清冊 + 右側詳情或獨立詳情頁，不把各類型做成互相覆蓋的多套首頁。
- C 工單負責現場故障與拆裝；R 工單只追拆下壞件。
- P 回填發現異常時，從細項直接建立或更新 C 工單，保留來源檢查區段與項目。
- 正式狀態修改、完工與拆裝都要產生事件或操作歷程。

## 4. 預檢管理

### 4.1 頁面

| 路由 | 頁面 | 功能 |
| --- | --- | --- |
| `/precheck` | 月曆總覽 | 預設首頁；依月查看 P 工單與狀態 |
| `/precheck/packages` | 作業包 | 列印前確認、Word 套版與列印紀錄 |
| `/precheck/backfill` | 待回填 | 已列印未完工工單與開始回填 |
| `/precheck/backfill/:workOrderNo` | 完工回填 | 封面、檢查結果、附件、異常報修 |
| `/precheck/planning` | 排班規劃 | 日矩陣、自動排班、假日、人工調整與發布 |
| `/precheck/planning/annual` | 簡易排程驗證 | 車輛/機廠設備分開、年度切換、日期與間隔驗證 |
| `/precheck/imports` | 預排匯入 | Excel 預覽、驗證、錯誤列與確認匯入 |
| `/precheck/schedules/:scheduleId` | 排程詳情 | 預排來源、改期、產單、列印與完工狀態 |

預檢用到的儀器、用料預設、WI、Word 範本與檢查項目，統一由主檔設定維護；預檢頁只提供深層連結，不複製第二套後台。

### 4.2 車輛排班規則

1. 年度預排表決定每月檢修級別，最新實際完工日決定日期基準。
2. 各次預檢與上次施作以 30 天為目標，法規允許範圍為 24 至 36 天。
3. 系統可在裕度內往前或往後找工作日，避免留下可利用空班。
4. 優先順序：`3M / 6M / 1Y`、`1M`、鏇削。
5. 假日、國定假日與人工假日不自動排；人工仍可強制排入，並標示複核。
6. 新增臨時假日後，從受影響工項開始整段重排，後續日期一起重算容量。
7. 不能因排不進來而遺漏工項；超限時仍排最近可用日並標紅複核。

### 4.3 每日車輛容量

一日安排兩台車時，只允許：

- 月檢 + 鏇削
- 月檢 + 月檢
- 季檢第二天 + 鏇削
- 季檢第二天 + 月檢

機廠設備可加入同日作業，使當日總工項最多 3 筆，但不能突破車輛組合限制。

### 4.4 鏇削規則

1. 鏇削只由車輛 `3M / 6M / 1Y` 觸發，不用上一筆鏇削日期自行推算。
2. 先排高階檢修，再優先往前找 2 個可用工作日安排鏇削。
3. 高階檢修在月初時，鏇削可以跨到前一個月月底。
4. 一天只能一台鏇削。
5. 無法往前安排時才評估後排；未排入或順序不合理必須複核。

### 4.5 機廠設備排班規則

1. 年度表同時決定本月檢修級別與設備固定週期。
2. 固定週期依全年最短週期判斷：有 `1M` 用 1M，否則依序取 `3M / 6M / 1Y`。
3. 日期以最新實際完工日或前月完工日加固定週期推算，不使用上一次同級檢修。
4. 當月顯示級別仍照年度表。
5. 可後排設備可優先排至當月後方可用工作日，但不得超過允許上限。
6. 首批可後排設備包含「拉線車兼高空維修作業車」。

### 4.6 顯示與驗證

- 2026 年 5 月以前資料顯示灰色「既有 / 不驗證」。
- 2026 年 5 月起才驗證建議排程。
- 簡易排程每格顯示級別、起訖日期、與前次間隔、鏇削起訖與「複核」。
- 完整複核原因放 tooltip，例如間隔超出、鏇削未排、假日強制排入、容量強制排入。
- 月曆狀態：待回填 D 與 D+1 為橘色；D+2 起為紅色；如期完成為綠色；完工日與排程日不同為紅色複核。

### 4.7 作業包與列印

作業前確認項目：

- 工單與車號/設備
- 預檢級別與工作類別
- 儀器與校驗效期
- WI 編號
- 用料預設與本次調整，例如空調濾網預設 N/A、需要水洗時再切換
- Word 範本版本與列印份數

正式輸出：

1. 作業前列印原始 Word 格式，不改版面。
2. 作業完成後可再次輸出已回填封面與附件供蓋章。
3. 每次輸出保存列印人、時間、範本版本與檔案雜湊/路徑。

### 4.8 完工回填

回填分四部分：

1. 封面完工資料：施工/完工日、人力、工時、危險工時、處理情形。
2. 依 P1/P2/P3/P4 模板顯示不同區段與檢查項目。
3. 量測項目：累積里程、碳刷、絕緣、溫度、日期等，依模板決定必填與標準。
4. 附件：例如 P1 座椅確認圖與電磁式軌道煞車量測紀錄。

異常必須在發生細項下處理：

- 建立新 C 工單
- 更新既有 C 工單
- 僅記錄（需權限與原因）

座椅圖以實際 M5 至 M1 配置建模，可點座椅標 X；每個 X 都要連動異常說明與報修處理。量測附件依六個測點保存原始值、磨耗距離與判定。

## 5. 周轉件管理

| 路由 | 頁面 | 功能 |
| --- | --- | --- |
| `/turnaround` | R 單清冊首頁 | 來源 C 單、拆下件、位置、狀態、風險與待辦 |
| `/turnaround/r-orders/:workOrderNo` | R 單詳情 | 正式處理、外修、驗收、回庫、報廢與歷程 |
| `/turnaround/matrix` | 坑位矩陣 | 車號 x 坑位的快速現況判斷 |
| `/turnaround/assets` | 設備名稱總覽 | 同型設備、序號、庫房與狀態 |
| `/turnaround/assets/:assetId` | 設備履歷 | 設備序號事件時間軸與關聯工單 |
| `/turnaround/positions/:positionId` | 坑位履歷 | 某坑位歷來裝用與拆出紀錄 |

矩陣最終規則：

- 左側車號與頂部設備欄 sticky，表格內提供明顯橫向捲動。
- 格子只顯示序號、健康狀態、最近工單/日期。
- 點格子後右側只顯示現況：車號、坑位、設備、序號、物料、狀態、來源工單、最近更換、庫房備品與 C/R 摘要。
- 不在矩陣右側放履歷 Tab、工單動作或正式狀態更新。
- 設備履歷與坑位履歷使用獨立頁面；正式 R 動作只在 R 單詳情。
- 庫房摘要必須與所選設備類型連動，不顯示無關設備。

## 6. 物料庫存

| 路由 | 頁面 | 功能 |
| --- | --- | --- |
| `/inventory` | 物料清單 | 搜尋、系統、類型、狀態與庫存摘要 |
| `/inventory/materials/:partNo` | 物料詳情 | 主檔、位置、交易、用量、補料判斷 |
| `/inventory/documents` | 庫存異動單 | 領料、退料、調撥清冊 |
| `/inventory/documents/new` | 新增異動單 | movement type、來源、目的、明細 |
| `/inventory/documents/:id` | 異動單詳情 | 草稿、確認、過帳與歷程 |

目前決策：

- 保留領料、退料、調撥與工單耗用。
- 安全庫存使用統一 `reorder_point`，暫不分淡海/安坑。
- 補料決策是提醒與分析，不建立請購單號。
- 暫不做正式盤點單。

## 8. API 現況與缺口

| 範圍 | 目前狀態 | 下一步 |
| --- | --- | --- |
| 物料查詢與主檔 | 已有 API | 統一分頁與錯誤契約 |
| 庫存摘要與異動 | 已有主要 API | 增加異動單草稿/過帳契約與權限 |
| 工單清冊與完工 | 已有原型 API | 正式化 P/C/R/J DTO、分頁與事件 |
| 設備事件 | 已有轉移與履歷 API | 增加矩陣現況、設備總覽與坑位履歷查詢 |
| 倉庫與流程選項 | 已有 API | 補人員、車輛、儀器、WI 與模板 API |
| 預檢排程 | 尚缺 | 新增匯入、月曆、排班、發布、改期 API |
| Word 套版列印 | 尚缺 | 新增範本、欄位 mapping、print job 與檔案輸出 API |
| 預檢回填 | 資料表已預留、API 尚缺 | 新增草稿、驗證、完工與異常轉 C API |
| 儀表板 | 尚缺聚合 API | 以角色提供待辦與摘要，避免前端拼多個大量查詢 |

資料庫仍需補強：`pm_schedule_import_batch`、`pm_schedule_item`、`pm_schedule_change_log`、`form_template`、`form_template_field_mapping`、`work_order_print_job`。
